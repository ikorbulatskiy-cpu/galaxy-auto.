# NEXORA

**Meet. Connect. Discover.**

NEXORA — социальная платформа знакомств и виртуальный мир для совершеннолетних пользователей (18+).

## Текущий статус

Ветка разработки: `love-galaxy-redesign`.

### Реализовано в текущем этапе
- Адаптивная стартовая страница и демонстрационные карточки.
- Express API.
- PostgreSQL-схема для аккаунтов, профилей, персонажей, авторитета, планет, перелётов, наказаний, кошельков, друзей, лайков, блокировок, жалоб и сообщений.
- Регистрация с проверкой возраста 18+ и хешированием пароля bcrypt.
- Подтверждение email одноразовым токеном с ограниченным сроком действия.
- Вход, выход и серверные сессии с HttpOnly cookie.
- Rate limiting для auth API, Helmet, ограничение JSON body и проверка Origin для изменяющих запросов.

### Пока не реализовано
- Клиентские экраны регистрации и входа, подключённые к API.
- Восстановление пароля и повторная отправка письма.
- Редактор персонажа и визуальные ресурсы аватаров.
- Начисление авторитета и антинакрутка.
- Реальное перемещение между планетами и присутствие игроков.
- Игровая тюрьма и действия персонажей.
- WebSocket-чаты, модераторская панель и магазин.
- Платёжные интеграции, проверка возраста внешним провайдером и production-проверка безопасности.

## Требования

- Node.js 20+
- PostgreSQL 14+
- SMTP-сервер для подтверждения email в production

## Настройка

1. Скопируйте `.env.example` в `.env` и заполните `DATABASE_URL`.
2. Создайте базу PostgreSQL.
3. Установите зависимости: `npm install`.
4. Примените схему: `npm run db:migrate`.
5. Запустите: `npm start`.

Для production обязательно настройте `NODE_ENV=production`, `APP_BASE_URL`, SMTP-переменные и HTTPS. В production регистрация не будет отправлять токены подтверждения в лог вместо email.

## API

- `GET /api/status` — состояние сервера и БД.
- `POST /api/auth/register` — регистрация. JSON: `email`, `username`, `password`, `birthDate` (YYYY-MM-DD).
- `GET /api/auth/verify?token=...` — подтверждение email.
- `POST /api/auth/login` — вход. JSON: `email`, `password`.
- `GET /api/auth/me` — текущий пользователь.
- `POST /api/auth/logout` — завершение сессии.

## Важное

Текущая версия — первый backend-этап, а не готовый публичный сервис. Не размещайте её в production до подключения SMTP, проверки миграций и тестирования, добавления восстановления пароля, CSRF-защиты с токеном, модерации и процедур удаления персональных данных.
