# NEXORA

**Meet. Connect. Discover.**

NEXORA — прототип социальной платформы для знакомств и общения (18+).

## Текущий этап

- Адаптивная главная страница для мобильных устройств и компьютеров.
- Демонстрационные карточки анкет и фильтр интересов.
- Демонстрационные действия лайков.
- Макеты входа и регистрации.
- Express-сервер и endpoint проверки состояния: `GET /api/status`.

> Важно: текущая версия — интерфейсный прототип. Регистрация, база данных, загрузка фотографий, реальные лайки, совпадения и чаты ещё не подключены. Демо-анкеты вымышленные.

## Запуск локально

Требуется Node.js 18 или новее.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## План разработки

1. PostgreSQL и схема пользователей/анкет.
2. Безопасная регистрация, вход, восстановление доступа и подтверждение email.
3. Редактирование профиля и безопасная загрузка фотографий.
4. Поиск, лайки и взаимные совпадения.
5. Личные сообщения и уведомления.
6. Жалобы, блокировки, модерация и удаление аккаунта.
7. Проверки безопасности и подготовка к публикации.

## Возраст и безопасность

Платформа проектируется для совершеннолетних пользователей (18+). Перед публичным запуском необходимы реальные механизмы проверки возраста, согласия с документами, модерации, защиты персональных данных и обработки жалоб.
